# 小秘書

不需要帳號的清單小秘書。資料只存在使用的那台手機的瀏覽器裡。

## 角色

角色圖是 `character.png`，顯示在左上角的蕾絲圓框裡。要換圖就用同名檔案覆蓋。

- 建議去背的 PNG，臉在上半部，邊長 400 到 800 像素
- 手機主畫面的圖示是 `apple-touch-icon.png`（180×180）與 `icon-512.png`（512×512），想換也是直接覆蓋同名檔案

## 檔案

- `index.html`：整個頁面
- `character.png`：角色圖
- `sw.js`：沒有網路時也能打開
- `manifest.webmanifest`：加到主畫面用的設定
